# Security policy

## Supported version

Security fixes target the latest code on `main` in the 0.1 development line. No commercial support or response-time guarantee is offered.

## Report privately

Use the repository's **Security → Report a vulnerability** option if private vulnerability reporting is enabled. If that option is unavailable, open a public issue containing only a request for a private reporting channel; do not include exploit details, confidential text, or secrets.

## Processing boundary

The browser compares text in memory. Imported text is displayed with text nodes rather than interpreted as markup. The CLI reads only the explicit paths you pass and writes only the explicit report path. Keep your local development server bound to loopback. JSON exports include the source and rewritten text and must be handled as sensitively as those drafts.

## Limits

Fact Fuse does not certify factual accuracy, semantic preservation, or suitability for regulated decisions. Language findings are review prompts. Report missed cases using sanitized fixtures rather than private documents.
