# Community code of conduct

Be constructive, respectful, and specific. Discuss behavior and evidence rather than personal characteristics. Welcome questions and give contributors room to learn.

Harassment, discrimination, threats, unwanted sexual attention, disclosure of private information, and repeated disruptive conduct are not acceptable in issues, pull requests, or project discussions.

Maintainers may edit or remove content, lock a discussion, or restrict participation to protect the community. To report conduct privately, use GitHub's reporting tools. If a private maintainer channel is needed, request one without posting personal details publicly. Maintainers apply proportionate action based on the context and pattern of behavior.
